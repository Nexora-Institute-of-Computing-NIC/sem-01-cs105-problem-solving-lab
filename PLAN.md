# CS105 — Problem Solving Lab — PLAN

**Semester:** 1 · **Credits:** 2 · **Level:** Beginner
**Theory:** 0 hrs · **Lab:** 45 hrs · **Platforms:** HackerRank, LeetCode, Codeforces

## Course Format
Pure practice. No new theory. Weekly problem sets that build coding fluency.

## Problem Categories

### Category 1 — Input, Output, Arithmetic (7 problems)
1. Hello, world
2. Sum of two numbers
3. Area and perimeter
4. Simple interest
5. Average of three numbers
6. Swap two numbers
7. FizzBuzz

### Category 2 — Conditionals (8 problems)
1. Even or odd
2. Largest of three
3. Leap year
4. Grade calculator
5. Triangle validity
6. Sign of a number
7. Simple calculator
8. BMI calculator

### Category 3 — Loops (10 problems)
1. Multiplication table
2. Sum of first N natural numbers
3. Factorial
4. Fibonacci series
5. Prime check
6. Reverse a number
7. Sum of digits
8. Palindrome number
9. Armstrong number
10. Pattern printing (right triangle, pyramid)

### Category 4 — Arrays and Strings (10 problems)
1. Array sum and average
2. Maximum and minimum in an array
3. Second largest element
4. Reverse an array
5. Count even and odd
6. Count vowels in a string
7. Reverse a string
8. Palindrome string
9. Anagram check
10. Frequency of characters

### Category 5 — Functions and Recursion (8 problems)
1. Function to check prime
2. Function to compute power
3. Recursive factorial
4. Recursive Fibonacci
5. Recursive sum of digits
6. Recursive GCD
7. Towers of Hanoi
8. Binary search recursively

### Category 6 — Mixed / Contest Prep (7 problems)
1. Sorting an array (bubble, insertion, selection)
2. Matrix multiplication
3. Transpose a matrix
4. Sieve of Eratosthenes
5. Count occurrences of a substring
6. String compression
7. Basic hashing with an array

## Labs (15 weekly drills)

1. Set up accounts and test run on HackerRank
2. Arithmetic drill — 10 easy problems
3. Conditionals drill
4. Loops drill 1
5. Loops drill 2
6. Arrays drill 1
7. Arrays drill 2
8. Strings drill 1
9. Strings drill 2
10. Functions and recursion drill
11. Mixed contest — 60-minute timed set
12. Mock contest 1 — 90 minutes
13. Mock contest 2 — 90 minutes
14. Mock contest 3 — 90 minutes
15. Reflection — patterns and weaknesses

## Assignments
Each week's problems are the weekly assignment. Submission = accepted solutions on the platform plus a short writeup of the approach taken for the hardest problem.
